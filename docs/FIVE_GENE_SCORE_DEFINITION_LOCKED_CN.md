# 5基因程序评分：锁定定义

锁定日期：2026-08-21  
版本：v1.0  
状态：**冻结；后续验证不得因生存结果修改基因、权重或主分析模型。**

## 1. 名称与用途

工作名称：**5-gene remodeling–cytoskeleton program score**  
中文名称：**5基因重塑–细胞骨架程序评分**

该评分用于检验连续表达程序与总体生存的关联。现阶段不称为可直接用于单个患者的绝对风险计算器。

## 2. 固定基因与权重

| Gene | Weight |
|---|---:|
| PLOD2 | 0.2 |
| MSN | 0.2 |
| TPM4 | 0.2 |
| PPFIBP1 | 0.2 |
| SEC31A | 0.2 |

不使用LASSO或Cox回归系数；五个基因等权。

## 3. 表达预处理

在每个队列内独立完成下列步骤：

1. 基因符号统一为大写官方符号。
2. pdacR队列的多个探针映射至同一基因时取表达均值。
3. GSE57495主分析对同一基因选择方差最高的探针；所有探针取均值作为敏感性分析。
4. 五个基因必须全部存在；若缺失任一基因，不以剩余基因替代或重新加权。
5. 不利用生存结局选择探针、标准化方式或参数。

## 4. 计算公式

对队列 \(c\) 中样本 \(i\)、基因 \(j\)，先进行队列内基因标准化：

\[
Z_{ijc}=\frac{X_{ijc}-\mu_{jc}}{\sigma_{jc}}
\]

其中，\(\mu_{jc}\) 和 \(\sigma_{jc}\) 分别是基因 \(j\) 在队列 \(c\) 中的表达均值和标准差。

五基因等权均值：

\[
M_{ic}=\frac{1}{5}
\left(
Z_{\mathrm{PLOD2}}+
Z_{\mathrm{MSN}}+
Z_{\mathrm{TPM4}}+
Z_{\mathrm{PPFIBP1}}+
Z_{\mathrm{SEC31A}}
\right)
\]

为统一效应量，将 \(M\) 再标准化：

\[
Score_{ic}=\frac{M_{ic}-\overline{M}_{c}}{SD(M_c)}
\]

因此，Cox模型中的HR解释为：**评分每升高1个队列内标准差对应的死亡风险比。**

## 5. 主分析与分组规则

- 主分析：连续评分的Cox比例风险模型。
- 主效应：HR per 1-SD score及其95%CI。
- KM图仅作为可视化：每个队列使用自身评分中位数分为High/Low。
- 不把TCGA中位数直接用于不同芯片或RNA-seq队列。
- 不根据最优cutoff、maxstat或生存P值选择阈值。
- 当前没有可跨平台直接部署的绝对分值阈值。

## 6. 固定结局与队列角色

- 结局：总体生存（OS）。
- TCGA-PAAD：发现/内部支持。
- Moffitt GSE71729、Puleo E-MTAB-6134：外部验证。
- GSE57495：新增独立外部验证。
- 外部meta仅合并Moffitt、Puleo和GSE57495，不包含TCGA。

## 7. 固定校正模型

- TCGA：年龄（每10岁）+ AJCC分期（有序）+ 病理分级（有序）。
- Moffitt：T分期 + N分期 + 切缘 + 性别。
- Puleo：T分期 + N分期 + 病理分级 + 切缘 + 性别。
- GSE57495：分期。
- Clinical + CAF模型：在上述临床变量基础上增加预定义CAF12等权评分。
- 分子亚型校正仅作为敏感性分析，不替代临床主模型。

## 8. 已锁定的稳健性检查

- GSE57495探针聚合：最高方差探针（主分析）与所有探针均值（敏感性）。
- 留一基因分析：依次删除一个基因，但不得据此修改Full5主评分。
- 临床校正、Clinical + CAF校正和分子亚型校正。
- 外部队列固定效应meta及异质性I²。

## 9. 解释边界

该分值采用队列内标准化，适合跨平台检验关联方向和标准化效应，不是无需参照人群即可计算的临床绝对风险模型。DCA、校准曲线或固定临床cutoff需在建立并外部校准绝对风险模型后另行开展。
